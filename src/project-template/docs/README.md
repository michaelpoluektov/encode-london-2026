# Shadily Project Docs

This folder documents the exact graph shape and validation flow used by the app.

- `graph-json-schema.md`: the `graph.json` validation schema.
- `glsl-programming-guide.md`: practical GLSL authoring guidance plus Shadily compatibility notes.
- `glsl-node-parsing.md`: how custom GLSL node signatures are loaded and matched.
- `graph-validation.md`: how a parsed graph is validated into a runtime graph.
- `examples/`: runnable-style examples of graph and node layouts.
